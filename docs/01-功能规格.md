# CC++ 功能规格（净室）

> 来源：void++（`0-V-linuxdo/VoidPP`，grok.com 的插件化用户脚本，GPL-3.0）的 README 与插件说明，只提炼**做什么、何时做、边界条件**，不复制实现。CC++ 针对 claude.ai 的页面结构与接口独立实现。编号 `C-x.y` 供验收逐条对照。

## C-1 架构：一切皆插件

| 编号 | 规格 |
| --- | --- |
| C-1.1 | 内核只做：插件注册、依赖校验（未知依赖 / 循环依赖在启动时报错）、生命周期、设置存储、事件总线、i18n。内核不包含任何 claude.ai 相关逻辑。 |
| C-1.2 | 网络钩子、路由、DOM 观察、样式注入、提示条、界面插槽、输入框读写、对话定位、快捷键、脚本菜单都是 **API 插件**；设置面板、自定义 CSS、备份是 **核心插件**；其余为功能插件。 |
| C-1.3 | 插件声明 `dependencies`；启用一个插件会先启动它的依赖；依赖在仍被需要时不能关闭（开关置灰并说明被谁需要）；关闭最后一个依赖者后依赖自动停止。 |
| C-1.4 | 每个运行中的插件拿到一个 Scope：监听器、定时器、观察器、样式、挂载的节点都登记在 Scope 上，停用时自动撤销；停用后页面恢复原状。 |
| C-1.5 | 启动分两段：`document-start`（网络 / 路由钩子）与 `dom-ready`；启动抛错的插件被隔离并在 1.5 / 4 / 10 秒后重试，不影响其它插件。 |
| C-1.6 | 设置变化默认重启该插件；插件可自行处理以实现无闪烁的即时生效。 |
| C-1.7 | 只在顶层 claude.ai 文档运行；重复注入（两个脚本管理器）只运行一份。 |
| C-1.8 | 存储：claude.ai 的 localStorage，统一 `ccpp:` 前缀；其它标签页改设置时实时同步。 |

## C-2 设置面板（对应 void++ Settings UI）

- C-2.1 入口：头像菜单「CC++ 设置」、脚本管理器菜单、快捷键 `mod+shift+,`（可改 / 关）；可选输入框旁齿轮按钮。
- C-2.2 插件页：搜索（跨分类，匹配名称、说明、选项名）；分类：收藏、最近（3 天内新增或 7 天内更新）、全部、输入框、消息、对话、用量、通知、外观、精简、隐私、开发者（以及可选显示的核心 / API）。
- C-2.3 卡片：图标、标题、说明、开关、收藏 ☆、置顶 📌（置顶卡片排在当前分类最前）、选项（齿轮展开）、徽章（新、近期更新、需刷新、必需、出错及错误信息）。
- C-2.4 选项类型：开关、滑块（带单位）、下拉、单行文本、多行文本、颜色、按钮（可二次确认）；可按其它选项条件显示；「恢复默认」。
- C-2.5 需刷新才生效的插件切换后顶部出现提示条与「立即刷新」。
- C-2.6 其它插件可以向面板注册标签页（自定义 CSS、备份与关于）。
- C-2.7 Esc / 点遮罩关闭；跟随 claude.ai 明暗主题；窄屏布局可用。

## C-4 隐私与安全约束

- 只调用 claude.ai 同源接口；不读、不存、不外传 Cookie / token；组织 ID 只从 `lastActiveOrg` Cookie（公开标识）或 `/api/organizations` 获得。
- 不连接第三方服务器；不读取非目标请求的正文；网络钩子不修改 claude.ai 拿到的原响应。
- 不使用 `innerHTML` 拼接用户内容；所有 UI 在 Shadow DOM 中，或以 `data-ccpp*` 标记的少量节点插入 claude.ai 页面。
